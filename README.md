# og-crop-test

Static pages for testing how link previews crop Open Graph images (Scalar DOC-6361).

- `/current/` is today's 1200x630 card.
- `/option-a/` is 1200x630 with everything inside the centred 630 square.
- `/option-b/` is 1200x1200 with the content in the centred 2:1 band.

Append `?v=N` to a page URL when re-sharing it, so platforms fetch fresh.
